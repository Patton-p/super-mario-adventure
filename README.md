# 超级马里奥 · 蘑菇王国大冒险

纯 HTML / Canvas 横版闯关游戏，支持键盘和手机触屏，无需安装依赖。

## 操作

- A / D 或左右方向键：移动
- 空格：跳跃；空中再按一次进行二段跳
- J / X：火球攻击
- K / Shift：冲刺
- P / Esc：暂停

## 三个世界

1. 青翠原野：收集三枚高空徽章，探索弹簧与高台。
2. 暮色山谷：跨越移动平台与喷火机关，激活三座信标。
3. 熔岩城堡：击败三名精英解除封印，迎战城堡领主。

包含连击奖励、护盾、无敌星、多个检查点和 Boss 出场、三分之一血量对白、死亡演出。

## 本地运行

直接打开 `index.html`。游戏进度和最高分保存在当前浏览器。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存即可。
